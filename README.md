# 💊 Dashboard de Positivação — Varejo Farma

Dashboard web interativo desenvolvido para demonstrar o acompanhamento de **positivação de clientes, cobertura por fornecedor e vendas ingressadas** em uma operação fictícia do varejo farmacêutico.

> **Projeto demonstrativo:** todos os clientes, vendedores, gestores, fornecedores, códigos e valores deste repositório são **100% fictícios** e foram gerados exclusivamente para portfólio.

## 💡 Sobre o projeto

A aplicação transforma uma base comercial em uma interface de consulta com indicadores, filtros, matriz de positivação e visão de vendas por cliente e fornecedor. O projeto funciona diretamente no navegador, sem backend ou instalação de dependências.

## ⚙️ Funcionalidades

- Filtros por equipe, vendedor, status e busca de clientes
- Matriz de positivação por cliente e fornecedor
- Indicadores de clientes positivados e cobertura
- Visão de venda ingressada por cliente
- Totais e rankings por fornecedor
- Ordenação de colunas e paginação
- Exportação da visão filtrada para CSV
- Alternância entre tema claro e escuro

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da aplicação
- **CSS3** — interface, layout e temas
- **JavaScript** — filtros, cálculos, interações e exportação
- **Git & GitHub** — versionamento e publicação
- **GitHub Pages** — hospedagem estática

## 📂 Dados

A versão pública utiliza uma base sintética com centenas de clientes fictícios, equipes comerciais, vendedores, cidades, fornecedores e valores simulados. Nenhuma base corporativa original está incluída.
